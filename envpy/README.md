# envpy 

----

CLI that deals with multiple python environments

Setup - Create a 'cd' function in Profile (one-off), so environemnts are loaded as user cd to a dir 
Create - Create virtual environment 
Rename - When venv is loaded the name on PS1 (promt) is same as dir name, this command allows you to change it.
